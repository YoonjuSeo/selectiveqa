## 1. 목적과 연구 질문

Tier 0는 붕괴가 **무엇**인지(M2 LoRA 업데이트가 M1과 거의 직교하는 방향으로 재배치됨, 프롬프트로 되돌릴 수 없음)를 완성된 체크포인트에서 보였다. Tier 1은 이 재배치가 **학습 중 어떤 과정을 거쳐** 일어나는지를 loss 궤적으로 관찰한다. 기존 로그는 20-step 평균 aggregate loss만 남아 있어 UA와 Answerable을 분리할 수 없었다(Tier 0 f 불가 판정).

| ID | 질문 | 성격 |
|---|---|---|
| **Q1 재현** | 같은 설정으로 재학습한 EXAONE M2-r05가 붕괴(EM 급락, 답변 길이 증가)를 재현하는가? | 확증적 (다른 질문의 전제) |
| **Q2 경쟁** | 붕괴형(EXAONE)에서는 UA 예시가 Answerable 학습을 방해하는 흔적이 loss에 나타나고, 무손실형에서는 나타나지 않는가? | 확증적 |
| **Q3 UA 부담** | 붕괴형은 UA 타깃을 학습하는 데 더 오래 걸리는가(Tier 0 a의 사전분포 거리와 대응하는가)? | 탐색적 |
| **Q4 손상 위치** | Answerable loss의 악화가 `answerable` 필드 토큰이 아니라 `answer` 내용 토큰에 집중되는가(Tier 0 d의 83%와 대응하는가)? | 탐색적 |
| **Q5 시점** | 형식 회귀(답변 길이 증가)가 학습 중 언제 나타나는가? | 탐색적 (5.5 체크포인트 저장 시에만) |

**이 실험으로 주장하지 않을 것:** Q2~Q5가 모두 예측대로 나와도, 이는 붕괴가 *어떻게* 진행되는지에 대한 증거이지 *왜 EXAONE에서만* 일어나는지에 대한 증거가 아니다. 원인 변수 특정은 continued pretraining 대조군(보고서 6.3(b))의 몫으로 남긴다.

### 2.2 허용되는 유일한 변경: 로깅 콜백

- 콜백은 **읽기 전용**이다. 학습에 쓰는 loss는 기존과 같은 방식(배치 평균)으로 계산하고, 로깅용으로만 `reduction="none"`인 토큰별 loss를 별도로 집계한다. gradient 경로를 바꾸지 않는다.
- 저장 시점마다 어댑터 가중치의 NaN/Inf 점검을 추가한다(읽기 전용, Qwen3 s42 발산 재발 감시용).

### 2.3 의도적으로 바꾸지 않는 것 (재현을 위해)

| 항목 | 유지 이유 |
|---|---|
| BOS 미삽입 (Tier 0 g) | 원 실험 조건을 재현하는 것이 목적이다. BOS를 삽입한 조건은 별도의 탐색적 조건으로만 추가할 수 있다(8절). |
| `max_grad_norm` | 원 실험 값을 그대로 쓴다 `[확인 필요: 원 설정값 기입]`. Qwen3 발산 재발 방지 권고는 Tier 1 이후 적용한다. |
| 혼입률, 타깃 형식 | r05, null 형식 유지 |

## 3. 로깅 항목

매 optimizer step마다 아래 값을 기록한다.

| 로그 키 | 정의 |
|---|---|
| `n_ua`, `n_ans` | 배치 안의 UA 예제 수, Answerable 예제 수 |
| `tok_ua`, `tok_ans` | 각 그룹의 타깃 토큰 수 |
| `sum_loss_ua`, `sum_loss_ans` | 각 그룹 타깃 토큰 loss의 **합** (평균이 아닌 합으로 저장해 나중에 토큰 가중 평균을 복원) |
| `sum_loss_ans_field`, `tok_ans_field` | Answerable 타깃 중 `"answerable": true` 필드 구간 토큰 |
| `sum_loss_ans_content`, `tok_ans_content` | Answerable 타깃 중 `answer`·`evidence_span` 값 구간 토큰 |
| `loss_total` | 기존 방식의 배치 loss (검증용) |
| `grad_norm` | clip 이전 gradient norm |
| `example_ids` | 배치에 포함된 예제 ID (사후 재집계용) |

**토큰 구간 정의**는 학습 시작 전에 코드로 고정하고, 예제 5건을 손으로 확인한 결과를 이 문서에 첨부한다 `[확인 필요: 첨부]`.

## 4. 지표 정의

### 4.1 창(window) 집계

r05에서는 UA가 전체의 5%이므로 batch 16이면 배치당 UA가 평균 0.8건이고 UA가 없는 배치가 많다. 따라서 step 단위 UA loss는 쓰지 않고, **기존 로그와 같은 20-step 창**으로 토큰 가중 평균을 낸다.

- L_UA(w) = Σ sum_loss_ua / Σ tok_ua (창 w 안에서). 창 안에 UA 토큰이 없으면 **결측**으로 두고 0으로 채우지 않는다.
- L_Ans(w), L_field(w), L_content(w)도 같은 방식으로 계산한다.

### 4.2 1차 지표 (확증적)

| 기호 | 정의 | 대응 질문 |
|---|---|---|
| **ΔEM** | 재학습 M2의 Answerable EM − 같은 seed 기존 M1의 EM | Q1 |
| **R_tok** | 재학습 M2의 평균 응답 토큰 ÷ 같은 seed 기존 M1의 평균 응답 토큰 | Q1 |
| **G** | 경쟁 격차. 창별 G(w) = L_Ans^M2(w) − L_Ans^M1(w)를 2 epoch 구간(step 189~376)에서 평균한 값. L_Ans^M1은 **기존 M1 학습 로그**(Answerable만 학습했으므로 aggregate loss = Answerable loss)를 쓴다. | Q2 |

### 4.3 2차 지표 (탐색적)

| 기호 | 정의 | 대응 질문 |
|---|---|---|
| **t_UA** | L_UA가 처음으로 0.1 아래로 내려가 이후 3개 창 연속 유지되는 step | Q3 |
| **L_UA_early** | UA 토큰이 있는 처음 3개 창의 L_UA 평균 | Q3 |
| **ρ_content** | (L_content^M2 − L_content^M1) ÷ [(L_content^M2 − L_content^M1) + (L_field^M2 − L_field^M1)], 2 epoch 구간 평균. 기존 M1 로그로는 필드별 분리가 불가능하므로 **M1도 콜백을 붙여 재학습한 경우에만** 산출한다 `[확인 필요: M1 재학습 여부]` | Q4 |
| **t_fmt** | 중간 체크포인트 중 평균 응답 토큰이 M1 대비 ×1.5를 처음 넘는 step | Q5 |

### 4.4 "차이가 있다"의 판정 규칙

절대 임계값 대신 seed 변동을 기준으로 판정한다.

- **차등 있음:** 비교 대상 두 모델 간 차이가 ① 모든 seed에서 같은 방향이고 ② 크기가 두 모델의 seed 간 표준편차 중 큰 값의 2배 이상이다.
- **차등 없음:** 두 모델의 seed 간 범위가 겹치고 평균 차이가 seed SD 이하다.
- **미결정:** 위 둘 다 아니다.
- seed가 1개뿐이면 모든 Q2~Q5 판정은 자동으로 **탐색적**이 되며 "차등 있음" 대신 "차등 시사"로 표기한다.

## 5. 분석 절차

1. **콜백 검증 (분석 전 필수):** 매 step에서 (sum_loss_ua + sum_loss_ans) ÷ (tok_ua + tok_ans)가 `loss_total`과 1e-4 이내로 일치하는지 확인한다. 불일치가 있으면 분석을 중단하고 원인을 이탈 기록에 남긴다.
2. **학습 재현 확인:** 재학습 aggregate loss 곡선을 같은 seed의 원 학습 로그와 20-step 창 단위로 겹쳐 그린다. GPU 비결정성으로 완전 일치는 기대하지 않으며, 곡선 형태의 비교만 기록한다.
3. **Q1 판정** (6절 S0/S1). Q1이 "재현 실패"면 Q2~Q5는 EXAONE에 대해 해석하지 않는다.
4. **Q2 → Q3 → Q4 → Q5** 순서로 판정한다.
5. **(선택) 중간 체크포인트 분석:** `[확인 필요: 저장 간격, 예: 47 step마다 8개]`. 각 체크포인트에서 ① Answerable 200문항(λ 스윕과 같은 부분집합) EM과 평균 응답 토큰, ② 기존 M1 어댑터와의 코사인 유사도를 잰다.

해석은 서로 배타적이지 않다. 여러 시나리오가 동시에 성립할 수 있으며, 성립한 것은 모두 보고한다.

### 6.4 조합별 논문 서사

| 조합 | 5장의 결론 문장 |
|---|---|
| S1 + S2a (+ S3/S4/S5) | "붕괴는 학습 중 UA 목표와 답변 목표의 경쟁으로 시작되어, 가중치를 직교 방향으로 재배치하고, 그 결과는 프롬프트로 되돌릴 수 없다." (가장 강한 서사) |
| S1 + S2b | "붕괴는 재현되지만 학습 loss에는 드러나지 않는다. 가중치 기하와 생성 행동에서만 관찰되는 현상이다." (음성 결과지만 실무적 가치가 큼) |
| S1 + S2c | "loss 수준의 방해 크기는 붕괴를 설명하지 못한다." (경쟁 가설 기각, Tier 0 결론만 유지) |
| S0 | 기제 장을 "원 체크포인트 분석"으로 축소하고 재현성 문제를 한계에 명시 |
